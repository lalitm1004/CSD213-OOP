# CSD213 Project - Text Editor
A very simple text editor written using Java and the Swing framework

## Features
- Custom fonts and sizings saveable to RTF files.
- Selective changing of font stylings
- Bold and Italics
- Shortcuts for operations:
    - Ctrl + '+' for increasing font size
    - Ctrl + '-' for decreasing font size
- Word and Character count
- Find and Replace functionality
- Simple sketchpad to insert shapes

### Note
There may be a few bugs and edgecases here and there as I didnt have enough time to thoroughly test the editor.
